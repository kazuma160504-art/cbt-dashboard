# CBT 学習ダッシュボード（非公開）

医学部CBT対策の個人用ツール。**成績（分野別正答率）は個人情報のため、このリポジトリは必ず Private（非公開）で運用すること。**

## 中身
| ファイル | 内容 |
|---|---|
| `index.html` | 弱点分析ダッシュボード（QB分野別の正答率・間違い数・優先度・インターリーブ提案） |
| `tracker.html` | 間隔反復 復習トラッカー（SM-2 / Anki方式）。データはブラウザのlocalStorageに保存 |
| `data.js` | ダッシュボードの元データ。**ここだけ書き換えれば更新できる** |

## 使い方（閲覧）
- どれかのHTMLをブラウザで開くだけ（サーバー不要・オフライン可）。
- スマホ等で見るときは、このリポジトリのファイルをダウンロードして開く。

## 更新のしかた（正答率が変わったら）
1. QBオンラインの「分野別」ページで各分野の ◎○△× を確認。
2. `data.js` の対象行を書き換える：
   ```js
   ["2E","腎・泌尿器",51,[◎%, ○%, △%, ×%]],  // 演習済み
   ["1C","生理学",63,null],                    // 未着手
   ```
3. `window.CBT_UPDATED` の日付を更新。
4. コミット（GitHubのWeb上で直接編集→Commit でもOK）。

## 凡例
◎=カンペキ / ○=自信あり正解 / △=自信なし正解 / ×=間違えた
正答率 ＝ ◎＋○＋△（＝100−×）。
